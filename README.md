
# FieldForceConnect - QA Assignment

## Project Overview
This project covers manual testing API testing and UI automation testing of the FieldForceConnect application.

## 1. Manual Testing
- Test case documentation
- Field validation
- Bug reporting
- Excel-based test execution

## 2. API Testing
- GET
- POST
- PUT
- DELETE
- Environment variable configuration
- API response verification using Postman

## 3. Automation Testing
- Java
- Selenium WebDriver
- TestNG
- Maven

### Automated Test Scenarios
- Login verification
- Add customer
- Punch-in popup verification

## Execution

Run the automation tests using:

```bash
mvn clean test
```

Configure TEST_EMAIL and TEST_PASSWORD as environment variables before execution.
